# 3. UI/UX Design

## Arah visual
Modern, premium, minimal, jelas, dan tidak terlalu ramai.

### Palet warna
| Token | Nilai |
|---|---|
| Navy | #0B1020 |
| Surface | #171E35 |
| Primary | #6655E8 |
| Accent | #9A8CFF |
| Light | #F5F6FA |
| Success | #16A34A |
| Warning | #D97706 |
| Danger | #DC2626 |

Warna perlu diuji untuk contrast ratio dan aksesibilitas sebelum production.

### Tipografi
- Heading: Geist atau Inter.
- Body: Inter.
- Angka: Geist Sans.
- Ikon: Lucide.

### Aturan layout
- Spacing dasar 8px.
- Radius komponen 12–16px.
- Konsisten pada ukuran ikon.
- Satu warna aksen utama.
- Hindari terlalu banyak card dan border.
- Sediakan dark mode dan light mode.
- Gunakan skeleton/loading state dan empty state yang informatif.

## UX capture
Capture harus mudah diakses dari desktop dan mobile. Setelah upload, tampilkan:
- Nama file.
- Progress.
- Status pemrosesan.
- Hasil ekstraksi.
- Tombol koreksi/konfirmasi.
- Link ke dokumen asli.

## UX AI
- Tampilkan sumber jawaban.
- Bedakan fakta tersimpan dan saran AI.
- Minta klarifikasi ketika data tidak cukup.
- Jangan mengeksekusi aksi eksternal tanpa persetujuan.
- Sediakan feedback untuk jawaban yang keliru.
